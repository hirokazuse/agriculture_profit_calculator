# Agriculture

農業の採算、資金繰り、年間の経営判断を段階的に支援するプロジェクトです。

## 現在の方針

- 最初に作るものは、必要売価を即時に判断する簡易シミュレーターです。
- 実績管理・資金繰り・販売データ連携は、その後に独立モジュールとして追加します。
- 公開モックは実データを含めず、Vercelで別途公開できます。
- 本体は非公開で運用し、POS・EC・JA・市場などの自動連携を初期必須要件にしません。

## ディレクトリ

```text
apps/        実行可能なアプリ（管理アプリ、公開モック）
connectors/  CSV・API連携アダプター
docs/        要件定義と設計判断の正本
packages/    UIや保存先に依存しない共通ドメインロジック
```

実装開始前に、`docs/requirements/` の内容を確定します。
