# 論理データモデル（初版）

## 基本方針

農業の実態に合わせ、数量・重量・面積・金額・日付を分離して扱う。
販売単位を kg に固定しない。

## 主なエンティティ

| エンティティ | 主な項目 | 備考 |
|---|---|---|
| Farm | 名称、会計年度、開始時手元資金 | 初期は1事業体 |
| Crop | 作目名、品種、標準販売単位 | 例：トマト、kg |
| Field | 圃場名、面積、面積単位 | 面積換算を保持 |
| ProductionPlan | 作目、圃場、年度、想定収量 | 計画と実績を分離可能 |
| SalesChannel | JA、市場、直売所、ECなど | 入金条件を持つ |
| SalesScenario | 数量、表示単価、手数料、送料、梱包費 | 売価シミュレーション用 |
| CostItem | 費目、金額、発生日、支払予定日 | 作目別または共通経費 |
| CashEvent | 入金・支払・借入・返済・生活費引出し | 資金繰り計算の最小単位 |

## 重要な日付

| 日付 | 意味 |
|---|---|
| 販売日 | 売上が発生した日 |
| 入金予定日 | 実際に現金が入る見込みの日 |
| 購入日 | 原価・経費が発生した日 |
| 支払予定日 | 現金が出る見込みの日 |

損益計算では販売日・購入日を主に使い、資金繰りでは入金予定日・支払予定日を主に使う。
